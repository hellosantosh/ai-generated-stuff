4Accounts APIs

Five read-only views of a customer's brokerage accounts: which accounts you can reach, what they are worth, what they hold, what is working, and what has already happened.

4.1Account list

GET/v1/accounts
Requires accounts:read

Returns every account the presented access token is authorized to see. This is the entry point for everything else — the accountId returned here is the opaque, permanent handle used in every other path. 

GET /v1/accounts HTTP/1.1
Authorization: Bearer eyJhbGciOiJSUzI1NiIs…

→ 200 OK
{
  "items": [
    {
      "accountId":      "acct_01HQ8Z4M2X9K3P7R",
      "accountNumber":  "••••4471",
      "nickname":       "Main brokerage",
      "type":           "MARGIN",
      "registration":   "INDIVIDUAL",
      "status":         "ACTIVE",
      "baseCurrency":   "USD",
      "optionsLevel":   "LEVEL_3",
      "dayTrader":      true,
      "openedAt":       "2021-03-14T00:00:00Z",
      "_links": {
        "self":         { "href": "…/v1/accounts/acct_01HQ8Z4M2X9K3P7R" },
        "balances":     { "href": "…/balances" },
        "positions":    { "href": "…/positions" },
        "orders":       { "href": "…/orders" },
        "transactions": { "href": "…/transactions" },
        "place-order":  { "href": "…/orders", "method": "POST" }
      }
    }
  ],
  "_links": { "self": { "href": "…/v1/accounts" } }
}
FieldNotes
accountIdOpaque and permanent. Use this as your foreign key.
accountNumberCustomer-facing, masked to the last four digits unless the grant carries accounts:read:full. Display it; do not key on it.
typeCASH settles trade-by-trade and cannot borrow. MARGIN can, which changes buying power, short-sale eligibility, and available option strategies.
statusACTIVE, RESTRICTED, CLOSED, PENDING. A RESTRICTED account can be read but not traded — it carries no place-order link.
optionsLevelApproved strategies, cumulative. See §5.4.
dayTraderPattern-day-trader flag. When true, the 25,000 USD minimum equity rule applies and day trades are counted.

The list is deliberately unpaginated — a customer rarely has more than a handful of accounts, and forcing pagination onto a bounded collection buys nothing.

4.2Account balances

GET/v1/accounts/{accountId}/balances
Requires accounts:read

A balance snapshot, stamped with asOf. Intraday it reflects real-time marks on open positions and unsettled trade activity; after the close it settles to end-of-day values. 

→ 200 OK
{
  "accountId":            "acct_01HQ8Z4M2X9K3P7R",
  "currency":             "USD",
  "asOf":                 "2026-08-17T18:42:11Z",
  "netLiquidation":       "184320.55",
  "equity":              "184320.55",
  "positionsMarketValue": "142140.45",
  "cash": {
    "total":        "42180.10",
    "settled":      "39900.00",
    "unsettled":    "2280.10",
    "withdrawable": "39900.00"
  },
  "buyingPower": {
    "stock":      "84360.20",
    "option":     "39900.00",
    "dayTrading": "168720.40"
  },
  "margin": {
    "maintenanceRequirement": "38504.00",
    "initialRequirement":     "71140.22",
    "marginBalance":          "0.00",
    "excessLiquidity":        "145816.55",
    "marginCall":             null
  },
  "dayTradesUsed":      1,
  "dayTradesRemaining": 3,
  "patternDayTrader":   true,
  "_links": { … }
}
Buying power is three different numbers

They are broken out because they genuinely differ. In a margin account, stock is typically twice option — options cannot be bought on margin — and dayTrading is a larger figure that resets each session. Sizing an option order against buyingPower.stock will get it rejected, and the rejection will look mysterious if you were reading the wrong field.

FieldMeaning
netLiquidationTotal account value if every position were liquidated at current marks. The headline number.
cash.settledCash that has completed settlement. In a cash account, spending unsettled proceeds causes a good-faith violation — this is the figure that matters there.
cash.withdrawableWhat can actually leave the account today, after settlement and any holds.
margin.excessLiquidityCushion above the maintenance requirement. When this approaches zero, a margin call is imminent.
margin.marginCallNon-null only when a call is outstanding, carrying type, amount, and dueDate. The one field worth alerting on.
dayTradesRemainingDay trades left in the rolling five-business-day window before the PDT rule restricts the account.

Responses carry Cache-Control: no-store during market hours. Do not cache balances across a trade.

4.3Account positions

GET/v1/accounts/{accountId}/positions
Requires positions:read

Open positions, one row per instrument and side. Filter with instrumentType (EQUITY, ETF, OPTION) or symbol — the latter matches option positions on that underlying too. Paginated (§3.4). 

→ 200 OK — a long stock position and a short call written against it
{ "items": [
  {
    "positionId": "pos_01HQ9A1F4C8M2Q6T",
    "instrument": { "instrumentId": "inst_eq_AAPL", "type": "EQUITY",
                     "symbol": "AAPL", "currency": "USD" },
    "side": "LONG",
    "quantity":             "500",
    "contractMultiplier":   1,
    "averageCost":          "178.4200",
    "costBasis":            "89210.00",
    "lastPrice":            "231.1500",
    "marketValue":          "115575.00",
    "unrealizedPnl":        "26365.00",
    "unrealizedPnlPercent": "29.5539",
    "_links": { "self": {…}, "instrument": {…},
                "close-position": { "href": "…/orders", "method": "POST" } }
  },
  {
    "positionId": "pos_01HQ9A3H7D1N4S8V",
    "instrument": {
      "instrumentId": "inst_op_AAPL_20261218C00250000",
      "type": "OPTION", "symbol": "AAPL  261218C00250000", "currency": "USD",
      "option": { "underlyingSymbol": "AAPL", "expiration": "2026-12-18",
                   "strike": "250.00", "optionType": "CALL",
                   "exerciseStyle": "AMERICAN", "contractMultiplier": 100 }
    },
    "side": "SHORT",
    "quantity":           "-5",        // contracts, not shares
    "contractMultiplier": 100,
    "averageCost":        "12.4000",
    "marketValue":        "-4925.00",
    "unrealizedPnl":      "1275.00"
  }
] }
Options are counted in contracts

A quantity of -5 on an option position is five short contracts, which is exposure to 500 shares. Multiply by contractMultiplier (normally 100; adjusted contracts differ) to get share-equivalent exposure. Treating the two as the same unit understates option risk by two orders of magnitude.

quantity is signed — negative for short positions — so a naive sum across a portfolio nets long against short correctly. Long and short exposure in the same underlying are returned as separate positions. Closed positions do not appear here; use the transaction history for realized activity.

4.4Account order status

GET/v1/accounts/{accountId}/orders
Requires orders:read

Orders on the account, newest first. With no filter, this returns working orders only — PENDING_NEW, NEW, PARTIALLY_FILLED, PENDING_REPLACE, PENDING_CANCEL — which is the set a trading screen needs on load. Pass status explicitly, or the literal status=ALL, to widen it.

ParameterPurpose
statusRepeatable. One or more OrderStatus values, or ALL to disable the working-orders default.
symbolOne underlying, including its option orders.
from, toBounds on createdAt. Defaults to the last 7 days.
cursor, limitPagination (§3.4).
 
GET /v1/accounts/acct_…/orders?status=ALL&symbol=MSFT&limit=25

Single order, and its fills

GET/v1/accounts/{accountId}/orders/{orderId}
GET/v1/accounts/{accountId}/orders/{orderId}/executions
Requires orders:read  ·  single-order reads return a strong ETag

A single order can fill in many prints across several venues. executions is the audit trail behind filledQuantity and averageFillPrice: 

{ "items": [
  { "executionId": "exec_01HQ9E1A2B3C4D5E", "quantity": "100", "price": "412.48",
    "venue": "XNAS", "liquidity": "REMOVED", "executedAt": "2026-08-17T14:33:19.418Z",
    "settlementDate": "2026-08-19", "commission": "0.00" },
  { "executionId": "exec_01HQ9E4F5G6H7J8K", "quantity": "200", "price": "412.50",
    "venue": "ARCX", "liquidity": "ADDED",   "executedAt": "2026-08-17T14:35:02.771Z" }
] }
Poll cheaply, or do not poll at all

Single-order reads are limited to one request per second. Send the previous ETag as If-None-Match and an unchanged order costs you a 304 with no body. Better still, use the event stream in §5.7 and stop polling entirely.

4.5Account transaction history

GET/v1/accounts/{accountId}/transactions
Requires transactions:read

Cash and position activity: trades, dividends, interest, fees, transfers, assignments, exercises, expirations, and corporate actions. Ordered by tradeDate descending, then transactionId descending as a stable tiebreaker.

ParameterPurpose
from, toInclusive bounds on trade date. Defaults to the last 90 days; accepts any range up to 7 years.
typeRepeatable. Restrict to one or more transaction types.
symbolActivity in one symbol or its options.
 
GET /v1/accounts/acct_…/transactions?from=2026-08-01&type=TRADE&type=DIVIDEND

→ 200 OK
{ "items": [
  { "transactionId":  "txn_01HQ9C2K5M8P1R4W",
    "type":           "TRADE",
    "subType":        "BUY",
    "description":    "Bought 100 AAPL @ 231.05",
    "tradeDate":      "2026-08-15",
    "settlementDate": "2026-08-18",
    "instrument":     { "symbol": "AAPL", … },
    "quantity":       "100",
    "price":          "231.0500",
    "grossAmount":    "-23105.00",       // signed: negative reduces cash
    "fees": [ { "type": "REGULATORY", "description": "SEC Section 31 fee",
                "amount": "0.00" } ],
    "netAmount":      "-23105.00",       // gross net of fees — the actual cash movement
    "currency":       "USD",
    "relatedOrderId": "ord_01HQ9C1J3L7N0Q3V",
    "_links": { "self": {…}, "order": { "href": "…/orders/ord_01HQ9C1J3L7N0Q3V" } } },

  { "transactionId": "txn_01HQ9B8G4J2L6N9S",
    "type": "DIVIDEND", "subType": "CASH_DIVIDEND",
    "description": "AAPL cash dividend 0.26/share on 500 shares",
    "tradeDate": "2026-08-14", "grossAmount": "130.00",
    "fees": [], "netAmount": "130.00", "currency": "USD" }
] }
TypeCovers
TRADEBuys and sells. subType narrows to BUY, SELL, SELL_SHORT, BUY_TO_COVER.
DIVIDEND, INTERESTCash and stock dividends, credit interest.
FEE, TAXCommissions, regulatory fees, margin interest, withholding.
DEPOSIT, WITHDRAWAL, TRANSFER, JOURNALCash and position movement in and out of the account.
ASSIGNMENT, EXERCISE, EXPIRATIONOption lifecycle events. These arrive without an order — nobody placed one — so a reconciliation keyed on relatedOrderId will miss them.
CORPORATE_ACTIONSplits, mergers, spin-offs, symbol changes.
Reconcile on transactionId, not on position in the list

Settlement can back-date an entry, which means a transaction may appear in a page you have already read. transactionId is permanent and unique; deduplicate on it. Every example client in Section 6 does this rather than summing pages blindly.

Ranges wider than one year are served from cold storage and may take several seconds. Pull history incrementally and cache it locally rather than re-fetching seven years on every run.
