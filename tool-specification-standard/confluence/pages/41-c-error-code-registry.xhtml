Domain codes are registered centrally so that analytics can group them, customer-facing surfaces can localize them, and two teams cannot ship two spellings of the same failure. Adding a code is a pull request against this registry.

C.2 Registry rules

  • A domain code is permanent. Retire, never redefine.
  • SCREAMING_SNAKE_CASE, 64 characters or fewer, no product or system names.
  • Every code declares its taxonomy mapping and the fields its details object must carry. Those fields are what make the error actionable, and the contract test asserts them.
  • A code that fires more than 5% of the time for a tool is not an error; it is an undesigned path.
