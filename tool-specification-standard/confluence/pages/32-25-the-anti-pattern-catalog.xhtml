The pattern behind the patterns

Eleven of these twelve are the same mistake: optimizing for the convenience of the team building the tool rather than the reliability of the caller consuming it. One tool is easier to ship than four. Passing the upstream payload through is easier than shaping it. A generic error is easier than a mapped taxonomy. Each shortcut moves work from a place where it can be tested to a place where it can only be hoped for.
