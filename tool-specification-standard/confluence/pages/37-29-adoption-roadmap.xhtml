29.1 Maturity model

LevelStateCharacteristics
0Ad hocEach team invents its own tool format. No inventory. Nobody can say how many tools exist or what they can reach.
1InventoriedEvery tool is registered with an owner and a risk tier. Still inconsistent, but now visible — and visibility is what makes everything else possible.
2ConformantNew tools meet this standard and CI enforces it. Legacy tools are scheduled.
3CertifiedEvery customer-facing tool is L2 with evidence. Approval, audit, and kill switches work and have been exercised.
4SupervisedSelection accuracy and silent wrongness are measured continuously. Descriptors are improved from production evidence. The catalog is the inventory a regulator is shown.

29.2 A first year

HorizonDoDone when
Days 1–90 Ratify this standard. Stand up the catalog with names, owners, risk tiers, and hashes. Run the linter over every existing descriptor and publish the findings without blame. Pick one domain — brokerage read tools are the right first choice — and bring it to L2 as the worked example. Maturity 1, one domain at maturity 2
Days 91–180 CI gates mandatory for new tools. Evaluation suites for every tier 1 and above. Approval, audit, and kill switch wired through the gateway and exercised in a game day. Retire or schedule every unowned tool. Maturity 2 firm-wide
Days 181–365 Certify every customer-facing tool to L2. Red-team the tier 3 set. Stand up conversation sampling and the silent wrongness measure. Publish the tool inventory to risk and compliance as a standing report. Maturity 3, credible path to 4

29.3 Three ways adoption fails

FailureCounter
The standard is a document, not a gate Ship the linter in week one, before the debate about section 7 is settled. A rule that CI enforces is a rule; a rule in a PDF is a suggestion with formatting.
Retrofitting blocks everything Apply the full standard to new tools immediately, and to existing tools at their next change — except for the security and ownership rules (TS-SEC-02, TS-SEC-08, TS-GOV-01), which apply now. Perfect coverage later beats no coverage forever.
It is run as an API program The novel work is the prose, the evaluation, and the supervision — none of which an API governance function has ever had to do. Staff it with people who will read conversations, not only specifications.
