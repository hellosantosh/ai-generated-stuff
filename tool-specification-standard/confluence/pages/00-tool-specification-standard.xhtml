EA-STD-TOOL-001 · Draft for Architecture Review Board · v1.0.0-rc1

A normative standard for defining, describing, classifying, securing, and governing tools that a language model can invoke. It specifies a contract, not a wire protocol, so a conformant descriptor publishes over any tool-calling runtime without amendment.

Conformance levels

LevelNameRequiresPermitted exposure
GreenL0Registered Parses against the descriptor schema.Dev and test only.
BlueL1Conformant Every MUST satisfied; linter clean; named owner; structured errors; audit events. Internal agents, non-customer data, tier 0–1.
YellowL2Certified L1 plus security review, evaluation evidence, entitlement sign-off, SLO, kill switch, retention. Mandatory for customer data, money, or positions.
RedL3Externally exposed L2 plus egress assessment, contractual controls, tenant isolation proof, annual red team. Agents the firm does not operate.
The gating rule

TS-GEN-01. Every tool reachable from a production agent must hold at least Level 1. Every tool that reads customer data, moves money, changes an order, or writes to a system of record must hold Level 2.
