28.1 What the catalog must do

RuleLevelRequirement
TS-CAT-06RedMUST Be the single system of record for descriptors, serving them by name and version, with content hashes, to every runtime in the firm.
TS-CAT-07RedMUST Accept descriptors only from an authenticated publishing pipeline, never from a user interface, and MUST reject any that fail the linter or the meta-schema (TS-GEN-03, TS-GEN-05).
TS-CAT-08RedMUST Enforce global name uniqueness at publish time and refuse to reuse a retired name (TS-NAM-02, TS-NAM-11).
TS-CAT-09RedMUST Serve audience-scoped views resolved against the principal's entitlements, so a tool a principal cannot use is never placed in an agent's context (TS-GOV-03).
TS-CAT-10RedMUST Retain every published version indefinitely. An audit record naming a tool version is meaningless if that version cannot be retrieved.
TS-CAT-11YellowSHOULD Expose ownership, risk tier, lifecycle, dependencies, invocation volume, and evaluation results as a browsable inventory — the artifact a regulator asks for when they ask what the firm's agents can do.

Step 8 is not optional and is the one that gets dropped

A tool is not finished at publication because the caller is not finished learning. Selection accuracy in production diverges from the evaluation suite as real utterances arrive. Sampled, human-read conversations in the first four weeks catch descriptor defects that no offline suite will, and the fix is almost always one sentence of prose.
