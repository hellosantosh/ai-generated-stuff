Why the vocabulary is closed

It lets the linter check annotations against the name, lets policy be written against a name rather than an argument, and lets a reviewer infer a tool's shape before reading a word of prose. Extensions go to the ARB and are granted for new shapes, never for synonyms.

Titles

Yes

"Get order status"
"List the holdings in an account"
"Place a real order — trades money"
Sentence case · ≤60 chars · no trailing period · tier 3 names the consequence, not the operation.

No

"OMS order status retrieval (v2)"
"Order cancellation"
"View order" on a tool that cancels
A title that misstates the operation is a control failure, not a typo.

3The description

The model sees only name, title, description, and the input schema — including every property description. Nothing else. It reads them on every turn.

The seven parts

#PartWriteTest
1Purpose MUST One sentence, active voice, starts with the verb. Could a domain reader say what comes back?
2Use when MUST The questions this answers, phrased the way a customer phrases them. At least two real user phrasings?
3Do not use MUST Nearest neighbors, by exact wire name, with the distinction. Is every tool a confused reader might pick named here?
4Argument semantics Provenance of identifiers, units, cross-field rules. Could a careful caller still supply a well-formed but wrong value?
5Result orientation MUST Shape in a sentence, domain conventions, what empty means. Can the reader compute the right answer from the payload alone?
6Effects, freshness, cost MUST State change, money, staleness, rate limits. Would a compliance reviewer be surprised by an omission?
7Failure guidance The failures a caller can act on, and what to do. For each code: retry, change an argument, or stop?

Descriptions are attack surface

A description is an instruction injected into an agent's context. It is static, reviewed, signed, and hash-pinned — never generated at runtime, never templated with request data (TS-DSC-07, TS-SEC-09). It never instructs the agent about anything but itself (TS-DSC-06, TS-DSC-10).
