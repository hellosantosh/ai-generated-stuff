Shape rules

Root {"type":"object"} + explicit properties + explicit required + "additionalProperties": false. A no-argument tool still declares all four.
Size≤ 12 top-level properties, ≤ 2 levels deep SHOULD. Beyond that the tool is doing two jobs.
NameslowerCamelCase, domain vocabulary, and the same name means the same thing in every tool in the catalog.
BooleansNamed positively, defaulting to the conservative value: includeClosed: false, never excludeClosed: false.
IdentifiersOpaque, prefixed, pattern-constrained — acct_, ord_, inst_.
BoundsEvery array declares maxItems; every free-text string declares maxLength.
RequiredOnly if the tool cannot proceed without it. Marking a field required to make the model "think about it" makes it invent a value.
DefaultsThe narrow, least-surprising choice — and stated in prose, not only in default.

Make illegal states unrepresentable

"status":   { "type": "string" },
"symbol":   { "type": "string" },
"quantity": { "type": "number" },
"since":    { "type": "string" },
"limit":    { "type": "integer" }

// "open" "OPEN" "working" "aapl"
// "AAPL " 100.5 "last week" 10000
"status":   { "enum": ["WORKING", "FILLED", …] },
"symbol":   { "pattern": "^[A-Z]{1,5}$" },
"quantity": { "type": "integer",
              "minimum": 1, "maximum": 100000 },
"fromDate": { "format": "date" },
"pageSize": { "minimum": 1, "maximum": 100 }

// one way to be right

Enumerated values are SCREAMING_SNAKE_CASE and match Appendix D of the standard exactly. Where an enumeration is long or grows often, use a pattern plus a prose pointer to the tool that enumerates valid values. Where it is short and consequential — status, side, time in force, account type — spell it out. When two shapes genuinely differ, the answer is two tools, not a union.

Reserved parameter names

ParameterShapeSemantics
pageSizeinteger 1–100, default 25 Never limit, count, or top.
cursorstring ≤512 Opaque forward token. Offset and page numbers are prohibited against a moving book.
asOfdate-time Point-in-time read; omitted means now. A tool that cannot honor history must not accept it.
fromDate, toDatedate Inclusive window in the account's reporting time zone; declare the max span.
detailSUMMARY|STANDARD|FULL Verbosity. Preferred over a caller-supplied field list.
idempotencyKeyuuid Required on every non-idempotent state change. Dedupe ≥24h; replay returns the original result.
confirmationTokenstring ≤512 From the matching preview. Single use, ≤120 s, bound to the arguments.
reasonstring ≤280 Why the action is being taken. Captured verbatim into the audit record. Required at tier 3.

Prohibited input patterns

Never acceptBecause
Identity userId customerId onBehalfOf role tenantId Access control delegated to a language model. It will be talked into acting as someone else.
Credentials apiKey token password Secrets must never enter a context window — logged, retained, possibly forwarded.
Query languages sql filterExpression graphqlQuery jsonPath Unvalidatable, unauditable, injection surface with the model as injector.
Discriminators action operation mode command Collapses several risk profiles into one descriptor. Annotations, tier, approval, and audit all become wrong at once.
Safety flags force skipValidation dryRun override A flag that changes whether a tool is dangerous means the annotations describe one of two tools. Split them.
Caller-supplied URLs or paths Server-side request forgery primitive. Allow-list in configuration, never in an argument.
Unbounded arrays and blobsCost, latency, and denial-of-service vector.
Routing hints env region useCache debug Deployment facts the model must not be able to reason about or influence.
Anything the tool cannot honor The model will use it and silently receive an answer that does not match the request.

5Output & the result envelope

{
  "content": [{ "type": "text", "text": "3 positions in ••••8820 as of 14:32:05Z …" }],
                            // MUST ≥1 text block · generated FROM structuredContent, never hand-kept
                            // MUST carry as-of, currency, sign, and any truncation · keep it compact
  "structuredContent": {   // MUST validate against outputSchema · the authoritative payload
    "asOf":  "2026-09-19T14:32:05Z",        // MUST on anything that can change
    "basis": "DELAYED_15M",                 // MUST on any computed or convention-dependent figure
    "completeness": { "returned": 25, "totalMatching": 340,
                      "truncated": true,      // MUST on every collection; never null
                      "nextCursor": "eyJvIjoyNX0",
                      "narrowingHint": "Filter by symbol rather than paging." },
    "disclosures": ["Prices are delayed up to 15 minutes …"]   // compliance text lives here,
  },                                                             // not in the description
  "isError": false       // true = the tool ran and could not do its job. Transport failures never reach it.
}

Cut from every payload

Nulls · internal identifiers · hypermedia links · derivations the model can safely redo · per-row repetition of accountId, currency, asOf · pre-formatted display strings.

Numbers

Money, quantities Decimal strings — "62137.50". Never IEEE-754.
CurrencyISO 4217, at the value or the envelope.
FormattingNone in structuredContent. No separators, symbols, or parenthesized negatives.
TimestampsRFC 3339 with explicit UTC offset. Dates that are dates name their time zone.
SignsExplicit in the text rendering: -98,240.00 USD, SHORT 400.

Empty, partial, stale, truncated

SituationRequired behavior
EmptyisError: false, empty array, and prose saying what the emptiness means. A model shown a bare [] reports an outage about half the time.
Not foundNOT_FOUND for a get; an empty collection for a list. "That order does not exist" and "you have no orders" are different customer answers.
Truncatedtruncated: true and words in the text: "showing 25 of 340". Tell the reader how to narrow, not how to page — a model follows a cursor once, maybe twice, then summarizes what it has as if it were everything.
PartialOnly where the missing part is separable and disclosed. Name what is missing, in the text.
Partial, and the number gates a decision Fail instead. Balances, buying power, anything a trade depends on, must never be returned partially computed (TS-OUT-11).
StaleReturn it with an honest asOf and basis, plus stale: true past the freshness target. Let the reader decide; do not decide by hiding it.
