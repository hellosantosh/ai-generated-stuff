10Glossary and sources

10.1Terms used in this document

TermMeaning here
System One modelTypeSafe's proposed model class: unstructured state in, typed probabilistic decisions out, no text generation. Named for Kahneman's fast, automatic System 1 thinking.
Choice / Score / NoulThe three question primitives. Pick one of N; rate against a rubric; yes/no probability.
StateThe context you pass in — a string, JSON, or array of text — that all questions are evaluated against.
CalibrationWhether a stated probability matches observed frequency. A model is calibrated if things it calls 70% likely happen about 70% of the time. The property Jev's value rests on.
Expected calibration error (ECE)The standard measure of that gap. Meaningful only against a noise floor, which is why item 08 in the reading path computes one.
Temperature refitRescaling a model's probabilities after the fact so they become honest. A temperature of 3.4 means the raw outputs were substantially overconfident.
DecompositionSplitting one broad question into several narrow ones. On the phishing benchmark this moved accuracy from 62.6% to 95.0%.
RLCDReinforcement Learning for Calibrated Decisions — TypeSafe's stated training approach, optimizing probabilities against outcomes rather than human preferences.
JaggednessTypeSafe's own term for the uneven capability surface: strong on bounded judgment, weak on maths, dates and indirection.

The reading path in §9 is the durable part — those sources will keep being updated. The numbers in §2 and §7 should be re-checked before they are quoted anywhere that matters.
