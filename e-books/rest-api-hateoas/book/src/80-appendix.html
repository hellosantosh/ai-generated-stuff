Appendix B

Status codes and problem types

Every problem type the API can return, what it means, and what a well-written client does about it. Each type is https://docs.brokerage.example/problems/ followed by the name in the first column.

TypeStatusMeaningClient action
invalid-request400Malformed body, invalid fields (listed in errors), inconsistent prices, a bad cursor or limitFix the request; show field messages
idempotency-key-missing400A new order was sent without Idempotency-KeyAdd a unique key per order
unsupported-api-version400API-Version names an unknown version; supportedVersions lists the valid onesPin a supported version
unauthorized401No valid access tokenGet a token (see WWW-Authenticate), retry
insufficient-scope403The token lacks the operation's scopeRequest the scope; do not retry as is
trading-limit-exceeded403The order's notional exceeds the client's delegated limit (tradingLimit)Place a smaller order, or use a client with more authority
not-found404No such resource for this callerRe-navigate from the root
method-not-allowed405The resource does not support the methodUse the method its link or template names
not-acceptable406No representation matches AcceptAccept HAL or HAL-FORMS
order-not-cancellable409The order is final and cannot be canceledRe-read the order
order-not-replaceable409The order is final and cannot be changedRe-read the order
precondition-failed412The order changed since it was read (currentEtag)Re-read, reapply, resend with the new ETag
unsupported-media-type415The body's content type is not accepted hereSend JSON, or a merge patch for changes
idempotency-key-reused422The key was already used for a different requestUse a new key for a new order
insufficient-buying-power422The purchase needs more than is available (required, available)Show the amounts to the user
insufficient-position422Not enough shares to sell (available); short selling is not supportedReduce the quantity
instrument-not-tradable422The instrument does not exist, is halted, or cannot trade this wayCheck the instrument's properties
precondition-required428A change was sent without If-MatchRead the ETag first
rate-limited429The client's quota for the window is used upWait for Retry-After, retry with the same key

Every problem also carries instance (the request path) and requestId. An unexpected server error is a 500 problem with a request ID; quote it to support.

Appendix C

Glossary

Every term in one place, with the chapter that explains it.

Affordance
A description of an action a client can take, such as a HAL-FORMS template. (Ch. 12)
API root
The one URL a hypermedia client is configured with; everything else is reached by links. (Ch. 9)
Audience
The aud claim naming the API a token was issued for. (Ch. 20)
Backend for frontend (BFF)
A server-side component that runs OAuth for a browser app, so tokens never reach the browser. (Ch. 20)
Buying power
What a new purchase may spend: free cash, doubled in a margin account. (Ch. 7)
CURIE
A compact URI such as bk:orders, which expands to an extension relation's URI. (Ch. 10)
Cursor
An opaque marker of a position in a sorted collection, used for the next page. (Ch. 17)
Deprecation, Sunset
Response headers announcing that something is deprecated, and when it will stop working. (Ch. 19)
ETag
An entity tag identifying one version of a representation. (Ch. 8, 15)
Extension relation
A link relation defined by an API owner as a URI. (Ch. 10)
HAL
JSON Hypertext Application Language: JSON with _links and _embedded. (Ch. 10)
HAL-FORMS
HAL plus _templates describing the requests a client may send. (Ch. 12)
HATEOAS
Hypermedia as the engine of application state: clients advance by following links. (Ch. 9)
Idempotency key
A client-generated value that makes a retried request return the original result. (Ch. 14)
Idempotent method
A method whose effect is the same whether sent once or many times. (Ch. 3)
Link relation
The name of a link's meaning, such as self, next or bk:cancel. (Ch. 10)
Merge patch
A partial JSON document whose members replace the resource's (RFC 7396). (Ch. 15)
OCC symbol
The industry symbol for a listed option: root, expiration, C or P, strike times 1,000. (Ch. 8)
Optimistic concurrency
Allowing a change only if the resource is still the version the client saw. (Ch. 15)
PKCE
Proof Key for Code Exchange: binds an authorization code to the client that requested it. (Ch. 20)
Problem details
The RFC 9457 format for errors: type, title, status, detail, instance. (Ch. 16)
Protected resource metadata
An API's RFC 9728 document naming its authorization servers and scopes. (Ch. 20)
Representation
A document describing a resource's current state in some media type. (Ch. 2)
Resource
Anything important enough to have its own URI. (Ch. 2, 5)
Richardson maturity model
Four levels of REST adoption, from one endpoint to hypermedia. (Ch. 2)
Safe method
A method that does not change server state the client is responsible for, such as GET. (Ch. 3)
Scope
A named permission carried by a token, such as orders:write. (Ch. 20)
Server-sent events
A one-way stream of events over HTTP, with IDs for replay. (Ch. 18)
T+1
Settlement one business day after the trade date. (Ch. 6)
Tolerant reader
A client that ignores what it does not understand. (Ch. 6, 23)
Tool (AI)
A function an AI model may call, described by a name and a parameter schema. (Ch. 25)
Trading limit
The largest order a delegated client may place, carried in its token. (Ch. 20, 25)
URI template
An RFC 6570 pattern such as {?status,symbol} that a client expands. (Ch. 10)
