About this book

Every line of code printed here is read from the companion repository at build time. Every figure that shows a tool's output — an envelope, an error, a confirmation dialog, the generated system prompt, the conformance report, a run of the evaluation suite — is recorded from the running system by tools/capture.py and pulled into the text by the build. Nothing in this book is retyped, so a figure that disagrees with the code is a build failure rather than a reader's discovery.

A note on protocol

This book specifies a contract, not a wire protocol. A conformant descriptor is a JSON document; publishing it to any particular tool-calling runtime is an adapter, and the two adapters in the companion repository are one class each. Nothing in the specification names a transport, and nothing in it depends on one.

A note on the examples

The brokerage in these pages is a simulation. Its market data is generated deterministically, its accounts hold imaginary money, and no order placed by any example reaches a venue. The domain rules it enforces — settled cash, margin eligibility, short-sale permissions, pattern day trading, wash sales, T+1 settlement — are modeled closely enough to make the design decisions real, and loosely enough that nothing here should be mistaken for regulatory guidance or investment advice.
